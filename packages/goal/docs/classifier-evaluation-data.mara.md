# Synthetic classifier evaluation records

These normalized JSON Lines records preserve the synthetic inputs, preassigned labels,
question templates, frozen rule-selection procedure, and complete native classifier
responses for the [evaluation record](classifiers.mara.md). They contain no repository evidence or
user transcripts. Input to each native call was exactly `state` from its case and
`questions: { assessment: <matching task template> }`; expected labels, case IDs,
and split labels were not supplied to the classifier. The chronological attempt
number is local to each run. All pilot calls preceded calibration; rules were
frozen before any validation call. Native probabilities are not calibrated accuracy.

Original byte hashes identify the separately retained cache artifacts, not this
normalized representation. `frozen-rules.warning` preserves its pre-validation
wording; see the evidence item for the subsequently observed validation outcome.
The C108 expected label is retained unchanged despite the noted ambiguity.
