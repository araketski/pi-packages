## Scope
Provide /jobs controls using Pi UI components and public owner/observer/control interfaces, including output/truncation and historical diagnostics.

## Canonical contracts
- REQ-JOBS-CONTROL-SURFACE
- REQ-JOBS-CONTROL-SCOPE
- REQ-WORKFLOW-PRODUCER-INDEPENDENCE

## Observable acceptance
User controls match tool operations, present producer identity as opaque metadata, default to current-session jobs and explicitly inspect other records without acquiring authority. Local, Herdr-shaped and unknown conforming fixtures get identical semantics. UI registration must not redeliver results or take ownership. Honest unknown/expired/truncated states remain visible and stop-awaiting never fabricates success.
