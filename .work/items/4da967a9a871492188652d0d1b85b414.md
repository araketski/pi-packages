Own atomic external job/result records, bounded logs, shared quota accounting/reservations and retention under Pi user state.

## Observable acceptance
Specify concrete storage/locking/accounting and format before implementation. Test complete output within bounds, retained beginning plus rolling tail and explicit loss, concurrent distinct sessions/core copies sharing one quota, reserved completion capacity, protected pending/running/unknown records, eligible eviction and expiry. Refuse untrackable launches; after-launch write failures retain bounded honest in-memory tracking instead of killing work. New storage stays outside repositories and does not edit Pi session JSONL.
